# 工程图纸 PDF 半自动重命名

Windows 桌面小程序。用户在 PDF 预览中调整“物料编码、名称、工序编号”三个彩色识别框，OCR 只读取框内内容；人工确认全部文件后，程序统一安全重命名。

## 同事电脑一键安装与启动

推荐使用 Windows 10/11 和 64 位 Python 3.12（也支持 Python 3.11）。将整个项目文件夹复制到本地磁盘后：

1. 双击 `安装依赖.bat`：自动查找 Python、创建 `.venv`，优先使用清华大学镜像，失败时依次回退阿里云镜像和 PyPI 官方源。
2. 等待窗口提示“安装完成”。详细记录保存在项目内的 `安装日志\pip-install.log`，该目录不会提交到 Git。
3. 双击 `启动程序.bat` 运行软件；脚本会先检查运行环境，缺少依赖时会提示重新安装。

排错命令：

```bat
安装依赖.bat --check-only --no-pause
启动程序.bat --check-only --no-pause
启动程序.bat --console
```

`--console` 会保留控制台错误信息，适合程序无法启动时排查。安装脚本不要求管理员权限；若公司网络使用代理或安全软件拦截，请将 `安装日志\pip-install.log` 提供给维护人员。

## 当前功能

- 添加多个 PDF，或递归读取一个文件夹及其子文件夹中的真实 PDF 文件
- 单页 PDF 渐进式高清预览、缩放、左右旋转
- 适合窗口时使用轻量全页底图；放大或拖动停止后，仅将当前可见区域按需重绘，最高 300 DPI
- 切换 PDF 时继承上一份图纸的缩放倍率和相对视野位置，便于连续核对相同位置的标题栏
- 可手动为当前PDF按“湖州三井低温设备有限公司”生成三个建议框
- “自动建议框”开关默认关闭；打开时也只处理当前选中的PDF，不批量识别文件夹
- 蓝色物料编码框、绿色名称框、橙色工序编号框；框线固定为细 1 像素
- 支持新画、移动、右下角缩放及删除识别框
- 三个框完成后可点击“一键识别三个框”，并通过 0/3 至 3/3 的进度条查看当前字段
- 三个框完成但信息尚未识别时，蓝色主按钮自动变为“识别并下一份”；提交后台队列后立即打开下一份PDF
- 后台OCR严格单任务串行，文件列表显示“等待识别、识别中、待确认”，完成后仍须逐份人工核对
- 三个裁剪框在同一个独立子进程中批量识别，只加载一次文字模型；队列只保存小幅裁剪图
- 整页预览缓存最多保留最近3份PDF，避免连续处理大幅面图纸时内存持续增长
- 画完高亮框后不自动OCR；识别结果仍需人工核对，也可完全手工输入
- OCR在独立子进程中运行，底层识别库异常不会带崩主界面
- 单框OCR只运行文字识别模型，不再重复运行文字检测模型；超过20秒自动终止
- OCR运行时可点击顶部“取消识别”，关闭软件时也可取消当前任务
- 实时生成 `物料编码_名称_工序编号.pdf`
- `/` 及其他 Windows 非法字符自动替换为 `-`
- 全部人工确认后才允许批量重命名
- 同名文件和批次内重名会被阻止，不覆盖原文件
- CSV 操作日志保存在 PDF 所在目录下的 `重命名日志` 文件夹
- 点击“确认并下一份”时自动保存整窗确认画面、框坐标、OCR结果和置信度，可从左上角“历史记录”查看
- 历史记录支持按物料编码、名称、工序/工艺编码实时正则搜索，三项中任意一项匹配即可
- 批量重命名后，文件列表显示真实的新文件名，并提醒用户检查无误后再移动PDF
- 已重命名文件支持重新框选、重新识别和“重命名选中文件”单独修正；重新载入后只要新名称与当前名称不同也可直接修正
- 顶部“问题反馈日志”可查看运行日志并导出 ZIP 反馈包

## 开发运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe main.py
```

首次使用 OCR 会下载本地模型，之后识别过程在本机运行。无法初始化 OCR 时，程序仍允许手工框选和输入。

## 操作流程

1. 添加单页 PDF。
2. 默认直接显示PDF，不启动OCR；需要时点击“当前PDF生成建议框”，或主动打开“自动建议框”开关。
3. 点击蓝色“物料编码”、绿色“名称”或橙色“工序编号”标签，然后在PDF对应文字上按住鼠标左键拖拽。
4. 已生成的框可直接拖动；拖动右下角可缩放。也可按 `1/2/3` 后重新框选。
5. 只修改一个框时，可点击对应字段下方的“仅识别此框”；也可以直接手工输入。
6. 三个框完成后，点击蓝色“识别并下一份”：当前PDF加入后台串行识别队列，界面立即打开下一份，用户可继续框选。
7. 观察左侧“等待识别、识别中、待确认”状态。识别完成后返回对应PDF，人工核对或修改三个字段，再点击“确认并下一份”。
8. 所有文件确认且后台队列清空后，点击“执行批量重命名”。
9. 根据完成提示检查左侧新文件名，并可打开“历史记录”核对确认画面；顶部搜索框支持实时正则检索三个命名字段。
10. 如发现单个错误，选中该文件，重新框选和识别；新文件名预览与当前名称不同时，“重命名选中文件”会自动启用。

完成一个框后会自动进入下一个框选标签。按 `Esc` 可随时退出框选模式，恢复用鼠标左键拖动图纸。

快捷键：`1/2/3` 选择三个标签，`A/D` 左转/右转 90°，`空格` 执行当前蓝色主按钮，`Esc` 退出框选，`Delete` 删除选中框，`R` 仍可右旋，`Ctrl+Enter` 仍可确认并下一份。编辑文本时单键快捷键会暂时停用，点击窗口其他区域后恢复。

## 构建 Windows 发行版

发行脚本会同时生成联网安装版和包含 Python、依赖及 OCR 模型的免安装便携版：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File .\release\build_release.ps1 -Version 0.1.2
```

构建结果位于 `dist\release`。脚本仅按白名单复制运行文件，不会打包 `.venv`、Git 数据、
测试、PDF、截图、日志或历史记录，并会为 ZIP 生成 SHA-256 校验文件。
