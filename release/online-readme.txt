联网安装版

适用场景：
电脑可以访问互联网，并已安装 Python 3.11 或 Python 3.12 64 位版本。

首次使用：
1. 将压缩包完整解压到普通文件夹。
2. 双击“安装依赖.bat”，等待依赖下载和检查完成。
3. 双击“启动程序.bat”。

说明：
- 首次安装约需下载 1.4GB 运行依赖。
- 安装程序会依次尝试清华大学镜像、阿里云镜像和 PyPI 官方源。
- 如果安装失败，请保留“安装日志”文件夹并反馈。
- 图纸、历史记录和程序日志只保存在用户本机，不会上传到 GitHub。
- 顶部“检查更新”可下载新版联网安装包；下载后请按提示覆盖文件并重新运行“安装依赖.bat”。
