## 工程图纸 PDF 半自动重命名工具 v0.1.4

本次更新继续提供两种互为备用的下载方式：

- **windows-online.zip（联网安装版）**：体积小。需要 Python 3.11/3.12 64 位和网络，
  解压后先双击“安装依赖.bat”，完成后双击“启动程序.bat”。
- **windows-portable.zip（免安装便携版）**：已包含 Python、运行依赖和 OCR 模型。
  完整解压后直接双击 `DrawingPdfRenamer.exe`，请勿让 EXE 与 `_internal` 文件夹分离。

本次修复：

- 修复部分同事电脑点击“检查更新”时出现 `CERTIFICATE_VERIFY_FAILED` 的问题
- 更新连接同时信任 Windows 系统证书库和程序内置的 Mozilla CA 证书
- 保留完整 HTTPS 证书校验，不通过关闭安全验证绕过错误
- 证书仍异常时给出系统时间、Windows 根证书和公司 HTTPS 代理的排查提示

v0.1.3 已提供的更新功能继续保留：

- 启动后每天自动后台检查一次 GitHub 最新正式版
- 显示版本号、更新说明、安装包大小和下载进度
- 安装包 SHA-256 校验、免安装版自动替换、失败回滚和自动重启

主要功能：

- PDF 全页预览、放大高清重绘、旋转与人工彩色框选
- 切换 PDF 时保留上一份图纸的缩放倍率和相对视野位置
- 物料编码、名称、工序编号 OCR，以及人工核对和修改
- 后台串行 OCR 队列，可在识别当前图纸时继续框选下一份
- 批量重命名、单文件纠错、历史记录和正则搜索
- 历史记录重点显示三项识别结果，并支持确认后清除全部记录
- 快捷键调整为 `A` 左转 90°、`D` 右转 90°、空格执行蓝色主按钮
- 运行日志、异常退出保护和问题反馈包

安全说明：

- 发行包不包含用户 PDF、截图、历史记录、运行日志或开发虚拟环境。
- `CHECKSUMS-SHA256.txt` 提供两个 ZIP 的完整性校验值。
- Windows 或杀毒软件首次打开免安装版时可能进行安全扫描。
