## 工程图纸 PDF 半自动重命名工具 v0.1.6

本版本继续只提供 **Windows 免安装便携版**：

- 下载 `DrawingPdfRenamer-v0.1.6-windows-portable.zip`
- 将压缩包完整解压到一个新文件夹
- 双击 `DrawingPdfRenamer.exe`，无需安装 Python 或运行依赖安装脚本
- 请勿让 `DrawingPdfRenamer.exe` 与 `_internal` 文件夹分离

本次更新：

- 全新更新下载窗口，清晰显示进度百分比、已下载容量、实时速度和预计剩余时间
- 自动更新优先使用 Gitee 国内分卷镜像；镜像不可用时自动切换 GitHub 备用源
- Gitee 分卷在本机按顺序合并，并对完整 ZIP 执行 SHA-256 校验后再安装
- 新增原创项目 Logo，并同步用于主程序窗口、任务栏和 Windows EXE 图标
- 保留 v0.1.5 的多页 PDF、异常文件跳过和文件列表清理功能

已有功能：

- 多页 PDF 预览、翻页、放大高清重绘、旋转与人工彩色框选
- 物料编码、名称、工序编号 OCR，以及人工核对和修改
- 后台串行 OCR 队列，可在识别当前图纸时继续框选下一份
- 批量重命名、单文件纠错、历史记录和正则搜索
- 更新失败回滚、自动重启、运行日志和问题反馈包

安全说明：

- 发行包不包含用户 PDF、截图、历史记录、运行日志或开发虚拟环境
- `CHECKSUMS-SHA256.txt` 提供免安装 ZIP 的完整性校验值
- Gitee 与 GitHub 下载均只获取公开发行文件，不会上传图纸或识别结果
- Windows 或杀毒软件首次打开时可能进行安全扫描
