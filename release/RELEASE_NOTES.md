## 工程图纸 PDF 半自动重命名工具 v0.1.5

本版本开始只提供 **Windows 免安装便携版**：

- 下载 `DrawingPdfRenamer-v0.1.5-windows-portable.zip`
- 将压缩包完整解压到一个新文件夹
- 双击 `DrawingPdfRenamer.exe`，无需安装 Python 或运行依赖安装脚本
- 请勿让 `DrawingPdfRenamer.exe` 与 `_internal` 文件夹分离

旧联网安装版点击“检查更新”时，会自动改为下载免安装版，并提示迁移方法。

本次更新：

- 支持打开和处理多页 PDF，可用“上一页/下一页”切换页面
- 三个识别框可以位于不同页面，翻页后框选数据仍会保留
- 历史记录会保存确认时的页码和对应画面
- 批量重命名只处理“已确认”文件；异常、未确认或已处理文件会跳过，不再阻挡正常文件
- 文件列表新增“清空列表”，只清除当前界面数据，不删除 PDF、历史记录或日志
- Release 与发行脚本从本版本起停止生成联网安装包

已有功能：

- PDF 全页预览、放大高清重绘、旋转与人工彩色框选
- 物料编码、名称、工序编号 OCR，以及人工核对和修改
- 后台串行 OCR 队列，可在识别当前图纸时继续框选下一份
- 批量重命名、单文件纠错、历史记录和正则搜索
- 检查更新、下载进度、SHA-256 校验、自动替换、失败回滚和自动重启
- 运行日志、异常退出保护和问题反馈包

安全说明：

- 发行包不包含用户 PDF、截图、历史记录、运行日志或开发虚拟环境
- `CHECKSUMS-SHA256.txt` 提供免安装 ZIP 的完整性校验值
- Windows 或杀毒软件首次打开时可能进行安全扫描
