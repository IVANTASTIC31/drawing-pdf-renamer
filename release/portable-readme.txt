工程图纸 PDF 半自动重命名工具
Windows 免安装便携版

使用方法：
1. 将压缩包完整解压，不能直接在压缩包内运行。
2. 双击 DrawingPdfRenamer.exe。

说明：
- 已包含 64 位 Python、程序依赖和当前使用的 OCR 模型。
- 不要求电脑预先安装 Python。
- 第一次启动和第一次 OCR 识别可能稍慢。
- 请勿单独移动 EXE；EXE 必须和 _internal 文件夹放在一起。
- 图纸、历史记录和日志默认保存在用户本机，不会上传到 GitHub。
- Windows 或杀毒软件首次运行时可能进行安全扫描，请耐心等待。
- 顶部“检查更新”可下载正式版更新；程序每天最多自动检查一次。
- 更新包通过 SHA-256 校验后才会安装，更新失败时会尝试恢复旧版本。
